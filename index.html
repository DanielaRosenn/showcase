A small collection of instruments for looking at things that are usually hard to see.

  • Everything is static HTML, CSS and JavaScript. The 3D rendering uses three.js.
  • Earth Pulse reads public APIs directly from your browser. If a feed is unavailable, it falls back to a bundled snapshot.
  • On claude.ai, the apps can also call Claude to write briefings. On this site those features stay hidden.
